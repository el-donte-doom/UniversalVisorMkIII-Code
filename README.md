# Universal Visor Mk III — Code Repository

**This repository is for easier code contributions (if any).**  

It holds the source code and text-based configuration files for Universal Visor Mk III, a Doom mod. The repository is **not a playable mod** and contains no graphics or sound assets.

To play the actual mod, download the full release from ModDB. You can use the code here to review, modify, or propose changes via pull requests.
